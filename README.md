# Sci-Flipper 教師專業發展學習平台 - 完整複製品

本專案為針對 [Google Sites - Sci-Flipper 教師專業發展學習平台](https://sites.google.com/view/twteachertraining/home) 的 1:1 完整複製與優化版本。

---

## 專案功能與特色

1. **直接一鍵進入（免填縣市、單位、姓名與密碼）**：
   - 已依照需求將原先的「縣市選單」、「單位選單」、「姓名輸入」以及「密碼驗證」全面移除。
   - 使用者只需在首頁選擇視角（學員視角 / 教師與管理員視角），點擊 **「🚀 立即進入平台」** 即可免登入直接啟動研習工作區。
2. **完整研習工作區 (Dashboard)**：
   - 包含四大核心學習單元：生成式 AI 課堂應用、Sci-Flipper 跨領域社群共備、GULLA 即時學習回饋系統、課堂觀察量表與專業省思。
   - 內建 **GULLA AI 課堂教學回饋互動區**，可直接輸入教學難點或課堂反思獲得即時專業鷹架指引。
3. **高精準度視覺設計**：
   - 包含品牌 Logo、GULLA 系統標題、森林綠色調、細緻卡片陰影與流暢的動態反饋。
4. **線上託管 (GitHub Pages)**：
   - 支援免伺服器直接以 GitHub Pages 線上瀏覽，具備完整的跨載具與手機版 RWD 支援。

```

├── index.html        # 主網頁 (雙擊即可直接在瀏覽器預覽)

```
